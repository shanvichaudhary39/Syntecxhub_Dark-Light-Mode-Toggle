# Syntecxhub Dark-Light Mode Toggle

A simple and elegant dark/light theme toggler built using HTML, CSS, and JavaScript.

## Overview
This project demonstrates how to implement a modern theme switcher with smooth transitions and a clean UI. It allows users to toggle between dark and light modes with a single click.

## Features
- Dark mode and light mode toggle
- Smooth and modern UI transitions
- Responsive design
- Lightweight and beginner-friendly implementation
- Easy to customize for other web projects

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started

### Prerequisites
- A modern web browser
- Optional: local web server for preview

### Clone the Repository
```bash
git clone https://github.com/shanvichaudhary39/Syntecxhub_Dark-Light-Mode-Toggle.git
cd Syntecxhub_Dark-Light-Mode-Toggle
```

### Run the Project
Open `index.html` directly in your browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```

## How It Works
- The page loads with a default theme
- Clicking the toggle button switches between dark and light mode
- Theme state can be applied instantly using CSS classes and JavaScript logic

## Customization
You can easily change:
- theme colors
- button icon styles
- transition timing
- page layout and typography
